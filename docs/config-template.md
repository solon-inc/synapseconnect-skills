# SynapseConnect 設定メモ（雛形）

**0.8 以降、この設定メモは任意（上書き用）です。** 無ければ各スキルが `list_groups` から棚を自動で決め、
利用者が選んだ結果を `.synapse/shelves.json` に保存します
（優先順位: 設定メモ > `.synapse/shelves.json` > `list_groups` の自動解決 > 既定）。
自動解決の結果を固定したい・変えたい項目だけをこのメモに書けば、その項目だけが上書きされます。

固有値（グループの実名・ID・上限など）は**この1枚だけ**に置きます。スキル本文には書きません。
このファイルをコピーして必要な値だけ埋め、Claude プロジェクトのナレッジ（Claude Code なら CLAUDE.md の1節）に置いてください。
グループの構成が変わったら、直すのはこのメモ（または `.synapse/shelves.json` の削除）だけです。

```
# SynapseConnect 設定メモ

- ニュースグループ: <グループの名前または ID>
- ニュース投入の上限: 5件/回
- 会議記録の既定グループ: <グループの名前または ID。未設定なら「記憶の記録」のグループ特定手順に従う>
- 定期実行の報告先: <報告の宛先。例: この会話に1行で報告>

## 型付き記録（依頼・進捗・配信）
- タイムゾーン: <例: Asia/Tokyo>
- 全社共有: <グループの名前と ID>
- 開発チーム棚: <グループの名前と ID>

## 共有して
- SynapseConnect Console URL: <トップ URL>
- share.dry_run: true
- chatwork.tool: <投稿ツールの正確な名前>

| 宛先 | 棚 | Chatwork room_id | To account_id | 通知先 |
|---|---|---|---|---|
| <完全一致する表示名> | <名前と ID> | <room_id> | <個人向けでは必須> | 個人向け／全社向け／チーム向け |

## チーム（チームの今週 の対象）
- 自分: <表示名> / 個人棚 <名前と ID>
- メンバー: <表示名> / 個人棚 <名前と ID>
- メンバー: <必要な人数だけ追加>
```

- ここに書くのは「決め打ちが必要な仕事」の分だけです。ふつうの書き込み先は
  「記憶の記録」スキルが実行時に list_groups と「読む人」基準で決めます。
- 既定値: Console URL は `https://console.synapse-connect.ai/console`、`share.dry_run` は `true`、
  ニュース投入の上限は 5件/回、タイムゾーンは OS のローカルタイムゾーン。既定のままでよければ書かなくてかまいません。
- 宛先表（allowlist）が無いと `synapse-share` は配信記録を作ってもChatworkへは投稿せず、プレビューと手動投稿用本文だけを返します。
- パスワード・トークンなどの秘密は、このメモにも書かないでください。
- 個人棚は `classification=personal` だけで選ばず、表示名と棚 ID を1対1で明記してください。
- 読み共有されていない個人棚や書き込み権限のない棚は、設定に書いても利用できません。
- 宛先表は表示名を完全一致キーにします。`share.dry_run` は初回確認後に明示的に変えるまで `true` のままにします。
- Console URL と添付 URL は不透明な参照として扱い、分解・再構成しないでください。
