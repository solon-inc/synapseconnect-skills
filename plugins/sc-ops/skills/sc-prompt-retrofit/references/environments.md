# 環境別: システムプロンプトのありか・取得・設定方法

手順1（環境の確認）・手順2（取得）・手順9（設定案内）で使う。
「ありか」列の文は、ユーザーへの案内にそのまま使ってよい。

| 環境 | 見分け方（自動判定の手掛かり） | システムプロンプトのありか（案内文） | 自動取得 | 設定方法（書き戻し） |
|---|---|---|---|---|
| **Claude Chat**（claude.ai / ブラウザ） | 会話 UI のみ。ローカルファイルやシェルは使えない | プロジェクトを使っていれば、プロジェクト画面右側の「指示」欄。プロジェクト外なら「設定 → プロファイル」のカスタム指示 | 不可 → 貼ってもらう | 同じ「指示」欄に完成版を貼り直して保存 |
| **Claude Desktop** | Claude Chat と同じ UI（デスクトップアプリ） | Claude Chat と同じ | 不可 → 貼ってもらう | Claude Chat と同じ |
| **Claude Cowork** | デスクトップの作業ワークスペース。フォルダのファイルが読める | 作業フォルダの `CLAUDE.md`（あれば）、またはタスクの指示文 | フォルダ内の `CLAUDE.md` を探して読む | `CLAUDE.md` を編集・保存 |
| **Claude Code**（ターミナル / IDE） | シェル・ファイル操作が使える。`CLAUDE.md` が読める | プロジェクト直下の `CLAUDE.md`（プロジェクト用）と `~/.claude/CLAUDE.md`（全プロジェクト共通） | 可: 両方を読む | 該当の `CLAUDE.md` を編集。どちらに入れるかは適用範囲で選ぶ |
| **ChatGPT** | OpenAI の会話 UI | 「設定 → パーソナライズ → カスタム指示」。GPTs なら編集画面の Instructions、Projects ならプロジェクトの指示欄 | 不可 → 貼ってもらう | 同じ欄に貼り直して保存 |
| **Codex**（OpenAI Codex CLI） | ターミナルの agent。`AGENTS.md` が読める | リポジトリ直下の `AGENTS.md`（または `~/.codex/AGENTS.md`） | 可: `AGENTS.md` を読む | `AGENTS.md` を編集 |
| **Hermes** | 常駐エージェント。`~/.hermes/` が読める | `~/.hermes/SOUL.md` | 可: `SOUL.md` を読む | `SOUL.md` を編集（既存があれば退避してから） |
| **OpenClaw** | 非同期エージェント基盤 | エージェント定義ファイル（SOUL / persona。ありかは導入構成による） | 構成による | 定義ファイルを編集。ありかが不明なら管理者に確認 |
| **Gemini**（Gem） | Google の会話 UI | Gem の編集画面の Instructions 欄 | 不可 → 貼ってもらう | 同じ欄に貼り直して保存 |
| **その他 / 不明** | — | 「いま使っている画面・ツールの名前」を聞き、その製品の『カスタム指示』『Instructions』に相当する欄を一緒に探す | — | 見つけた欄に貼る |

## 注意

- 自動取得できた場合も、**提示して「これで合っていますか？」の確認**（手順3）を飛ばさない。
  別のファイルが正だったり、複数あることがある。
- Claude Code で `CLAUDE.md` が複数見つかったら、両方提示してどれを対象にするか選んでもらう。
- MCP 接続（SynapseConnect コネクタ）がまだの環境では、先に接続ガイドへ案内する
  （プロンプトだけ入れても道具が無ければ動かない）。
